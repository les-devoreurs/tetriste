# tetriste
Projet Algorithmes et Structures de donnée FIP_1A

## Packages
Le projet utilise SDL TTFont, pour l'utiliser :
sudo apt-get install libsdl2-ttf-dev

## Rappel CMake

Vider le cache CMake : 
rm -rf CMakeCache.txt CMakeFiles


Genérer le makefile avec Cmake : 
cmake .

Lancer le makefile : 
make
